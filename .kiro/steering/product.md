# Product Overview

This is a simple PDF upload/download web application designed as a demonstration project for security vulnerability scanning and remediation.

## Core Functionality
- Upload PDF files through a web interface
- Download previously uploaded PDF files
- File validation to accept only PDF files
- Simple HTML frontend with upload form and file listing

## Purpose
This application serves as a demo/educational tool to showcase:
- AI-generated code capabilities
- Security vulnerability detection using Snyk
- Automated vulnerability remediation workflows
- Integration with security scanning tools via MCP (Model Context Protocol)

## Known Security Issues
The application intentionally contains security vulnerabilities (particularly path traversal) to demonstrate vulnerability detection and remediation processes. These should be identified and fixed during development.
